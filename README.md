# AlgoViz

An interactive, full-stack data structures and algorithms visualizer designed to track step-by-step execution through animation.

##  Tech Stack
* **Frontend:** React (Vite), SVG Layouts, CSS
* **Backend:** Java, Spring Boot, REST API

##  Features
* **Sorting Visualizer:** Bubble, Selection, and Insertion Sort.
* **Graph Module:** BFS, DFS, and Topological Sort with real-time edge tracing.
* **Code-Tracker:** Dynamic pseudo-code highlighting synced with backend states.

---

##  Getting Started

### 1. Clone the Repository
```bash
git clone [https://github.com/ace81x/Algoviz](https://github.com/ace81x/Algoviz)
cd algoviz
```
### 2. Start Frontend
```bash
cd frontend
npm install
npm run dev
```
* Frontend runs on:
```bash
http://localhost:5173
```

### Start Backend
```bash
cd backend
./mvnw spring-boot:run
```
* Backend runs on:
```bash
http://localhost:8080
```

### Project Structure
```bash
AlgoViz/
```
